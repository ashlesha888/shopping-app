# Shopping App

A modern shopping cart application built with React, Redux Toolkit, and React Router. Users can browse products, add items to their cart, remove items, and receive real-time notifications for cart actions.

## Features

* Browse products
* Add products to cart
* Remove products from cart
* Cart item management using Redux Toolkit
* Toast notifications for user actions
* Responsive user interface
* Client-side routing with React Router
* Fast Vite-powered development and build process

## Tech Stack

* React
* Redux Toolkit
* React Redux
* React Router DOM
* React Toastify
* Vite
* CSS

## Installation

1. Clone the repository

```bash
git clone https://github.com/ashlesha888/shopping-app.git
```

2. Navigate to the project folder

```bash
cd shopping-app
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
